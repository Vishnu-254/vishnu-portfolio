Enterprise managed package, Accenture

Platform Core Managed Package

Project Overview

An enterprise 2GP managed package built from independently maintainable modules and installed into consumer orgs. I own it end to end, from requirements through release and installation support.

Business Challenge

Consumer orgs need common platform capabilities (trigger handling, error visibility, file storage, license control, access setup and login messaging) delivered consistently rather than rebuilt and maintained in every org.

Solution

Each capability ships as a module inside one versioned package. Releases go through Salesforce CLI and CI/CD pipelines, with beta versions before promotion, governor-limit checks and PMD standards.

Modules & Technical Contributions

Trigger Framework

Configurable trigger execution driven by Apex and Custom Metadata.

  • Standardizes trigger execution across multiple objects
  • Configuration through metadata rather than code changes
Error Logging & Consolidation

Signature hash-based consolidation of duplicate exceptions.

  • Detects duplicate errors by signature hash
  • Reduced error log records by roughly 80-90% within the first month
External File Storage

Salesforce and AWS S3 integration using pre-signed URLs.

  • Secure file uploads through pre-signed URLs
  • Delivery through CloudFront
  • Roughly 90% lower storage cost than native Salesforce file storage
User License Optimization

Finds unused licenses and automates deactivation.

  • Identifies inactive and underutilized users
  • Automates license deactivation to improve utilization of the existing subscription
Permission Sets

Packaged permission sets for consumer-org access.

  • Delivered with the package for consistent access configuration
Login Disclaimer

Screen Flow configured as a Login Flow.

  • Users acknowledge data security terms before completing login
  • Localized with Custom Labels and Translation Workbench

Security Center Automation

Project Overview

A parent-org solution that runs scheduled security assessments across connected orgs and consolidates findings into reports for org admins.

Business Challenge

Security reviews of each org were manual and repetitive, and needed heavy coordination with admins.

Solution

Scheduled Batch Apex jobs, configured through custom objects for connected orgs, scan schedules and assessment parameters, scan the Tenant Security objects and produce automated reports.

My Role and Contribution

  • Designed and built the full solution
  • Wrote scanning logic on TenantSecurityUserPerm, TenantSecurityLogin, TenantSecurityCertificate and TenantSecurityConnectedApp
  • Built automated reporting for monthly remediation follow-ups
  • Operational efficiency: replaced manual security scans of about 30 minutes per org across 30 tenant orgs with automated assessments and a monthly follow-up of about 5 minutes per org, cutting the monitoring effort for any developer overseeing security across multiple orgs

Enterprise implementation, Impaqtive

Media Rating Platform: Multi-Cloud Salesforce Implementation

Project Overview

An enterprise implementation spanning Sales Cloud, Service Cloud, Marketing Cloud, Field Service Lightning and Experience Cloud (LWR), connected through a shared Account and Contact data model. I contributed to configuration and development across every workstream, from lead conversion and case routing to journey automation and field scheduling.

Business Challenge

Bring lead management, case handling, outbound communication and field operations onto one platform with a consistent data model, while giving business users configurable control over rules such as campaign assignment.

Solution

Standard objects and features were extended with Apex, LWC and Flow where requirements needed custom behaviour. Shared records (Account, Contact, Lead, Case and a custom notification object) connect the clouds, so Sales, Service, Marketing and Field Service work from the same data.

Implementation Workstreams

Lead Conversion (Sales Cloud)

Criteria-based lead classification and conversion.

  • Leads are classified by business criteria and converted into Contact records under their Account
  • Optimized the lead conversion workflows to meet requirements
Rule-Based Campaign Assignment (LWC)

Configurable rules for campaign assignment.

  • LWC interface lets business users define field-based conditions, such as language and age, that combine to select a campaign
  • Apex logic evaluates the rules and assigns the matching campaign
  • Contributed as part of a sub-team
Case Management & Routing (Service Cloud)

Case management with Omni-Channel routing.

  • Omni-Channel routing with real-time workload balancing
  • Case assignment rules, plus SMS and email routing
Journeys & Communications (Marketing Cloud)

Notification-driven journeys.

  • Separate journeys per notification type, such as installation, confirmation and uninstall
  • A custom notification object with a type field drives journey selection
  • Data Extensions for segmentation and AMPscript templates for dynamic content
Field Service Lightning

Work and appointment management for field agents.

  • Work Orders and Work Types model the different kinds of field work
  • Service Appointments assigned to field agents
Self-Scheduling (Experience Cloud LWR)

Authenticated site for appointment booking.

  • Community users book service appointments through a custom LWR site
  • Removes the dependency on agent-initiated scheduling
  • Co-built with the team
Bitly URL Shortening (REST)

REST integration for outbound links.

  • Integrated the Bitly REST API to shorten URLs in outbound messages
  • Delivered as a dedicated user story
Salesforce Maps

Mobile route planning for field agents.

  • Assigned appointment locations visible to agents on mobile
  • Appointment scheduling and route optimization configured to requirements
Einstein Bot Appointment Confirmation

SMS-driven appointment confirmation.

  • Pre-configured text messages request appointment confirmation
  • Flows update the Service Appointment status from the reply
